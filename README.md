# Saath – Your AI Companion

Saath is an elderly-friendly AI companion designed to help elderly parents who live away from their children.

## Features

- Simple and elderly-friendly interface
- AI chat companion
- Call Family option
- Reminders option
- Emergency option
- Large buttons and readable text

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- OpenAI API
